TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Generate Documents" still not visible?
  → Check: SELECT slug FROM permissions WHERE slug = 'GENERATE_DOCUMENTS';
  → If empty: Run migration again
  → If exists: Clear browser cache (Ctrl+Shift+Del)

❌ 403 Forbidden error when accessing /documents/generate?
  → Registrar doesn't have GENERATE_DOCUMENTS permission
  → Run the migration: step 2

❌ Cannot find student in search?
  → Try searching by registration number (e.g., "STU-2024-001")
  → Try full name search (e.g., "John Smith")
  → Verify student exists in database

❌ Document preview not loading?
  → Check browser console (F12 → Console tab)
  → Verify API endpoint returns data: /api/documents/preview
  → Check server logs for errors


VERIFICATION QUERIES
═══════════════════════════════════════════════════════════════════════════════

Check if permission exists:
  SELECT id, slug, name FROM permissions WHERE slug = 'GENERATE_DOCUMENTS';

Check if registrar has permission:
  SELECT rp.* FROM role_permissions rp
  JOIN roles r ON r.id = rp.role_id
  JOIN permissions p ON p.id = rp.permission_id
  WHERE r.name = 'registrar' AND p.slug = 'GENERATE_DOCUMENTS';

List all registrar permissions:
  SELECT p.slug, p.name FROM role_permissions rp
  JOIN roles r ON r.id = rp.role_id
  JOIN permissions p ON p.id = rp.permission_id
  WHERE r.name = 'registrar'
  ORDER BY p.slug;
