================================================================================
  IF YOU DON'T SEE DATA
================================================================================

STEP 1: REFRESH PAGE
  • Hard refresh: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)
  • This clears browser cache and reloads from server

STEP 2: CLEAR BROWSER CACHE
  • Chrome/Edge: Ctrl+Shift+Delete → Clear all time → Clear data
  • Firefox: Ctrl+Shift+Delete → Everything → Clear Now

STEP 3: WAIT FOR SERVER CACHE
  • Wait 30-60 seconds after clearing cache
  • Server may be refreshing cache
  • Check again

STEP 4: TRY INCOGNITO/PRIVATE MODE
  • Open new private/incognito window
  • Go to https://cur.ac.rw/umis/finance/billing
  • This completely bypasses cache

STEP 5: CHECK DATABASE CONNECTION
  • If still blank after all above:
  • Database may be unreachable
  • Contact system admin to verify MySQL connection
  • Check if curac_save database is online
