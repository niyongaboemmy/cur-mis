TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Module dropdown shows "No modules found"?
  → Check department_id is valid
  → Verify modules exist: SELECT COUNT(*) FROM modules WHERE department = X
  → Check F12 console for API errors

API returns 422 error?
  → Verify department is numeric: ?department=5 ✓
  → Don't use: ?department=Department of CS ✗
  → Multiple depts: ?department=1,2,3 ✓

Slow loading (> 1 second)?
  → Run EXPLAIN to verify index usage
  → Rebuild index: REBUILD INDEX idx_modules_department_status ON modules;
  → Run: ANALYZE TABLE modules;

Module level not auto-filling?
  → Check module has level value in DB
  → Verify modal receives level field
  → Check F12 console for JS errors
