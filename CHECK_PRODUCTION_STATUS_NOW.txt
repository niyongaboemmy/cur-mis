❓ WHAT IF I SEE RED X?
================================================================================

If deployment failed (red X):

STEP 1: Click on the Red X
   Click on the failed workflow run

STEP 2: Click "Deploy to cPanel Production"
   Click the job name to see logs

STEP 3: Scroll to the Bottom
   Look for the error message

STEP 4: Read the Error
   Common errors:
   - "Permission denied" → SSH key issue
   - "not a git repository" → Git not initialized
   - "secret not found" → GitHub secret missing
   - "Connection refused" → Server unreachable

STEP 5: Tell Me the Error
   Send me the error message and I'll fix it!
