================================================================================
🔐 HOW TO CONFIGURE SSH - SIMPLE SUMMARY FOR YOU
================================================================================

Hi! Here's the simplest way to set up SSH so your code deploys to production.

================================================================================
WHAT IS SSH?
================================================================================

SSH is a secure way to connect to your production server.

WITHOUT SSH:
   You manually copy files → Slow, error-prone

WITH SSH (WHAT WE WANT):
   You push to GitHub → Automatic deployment to server in 10 seconds

So we need to set up SSH!

================================================================================
3 THINGS YOU NEED TO KNOW
================================================================================

1. SSH KEYS
   • 2 keys: id_rsa (private) + id_rsa.pub (public)
   • Private key stays on your computer (SECRET!)
   • Public key goes on the server

2. WHAT HAPPENS WHEN YOU CONNECT
   Your Computer          Server
   (id_rsa - private) ──> Check authorized_keys (public key)
                          ↓
                    Match? ✅ YES → Connected!
                           ❌ NO → Denied!

3. ONCE SSH WORKS
   • GitHub Actions can deploy automatically
   • You push → GitHub → Production (in 10 seconds!)

================================================================================
THE SETUP (COPY & PASTE)
================================================================================

STEP 1: Check if you have SSH keys
────────────────────────────────────
Open PowerShell and paste:

   ls $env:USERPROFILE\.ssh\

Look for: id_rsa and id_rsa.pub

IF YOU SEE THEM: Jump to STEP 4 below
IF YOU DON'T: Do STEP 2

─────────────────────────────────────

STEP 2: Create SSH keys (if you don't have them)
─────────────────────────────────────────────────
Open PowerShell and paste:

   ssh-keygen -t rsa -b 4096 -f "$env:USERPROFILE\.ssh\id_rsa" -N ""

Done! ✅

─────────────────────────────────────

STEP 3: Get your public key
────────────────────────────
Open PowerShell and paste:

   Get-Content $env:USERPROFILE\.ssh\id_rsa.pub

You'll see something like:

   ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAACAQDa5Z8x9q2x8v9k...

👉 SELECT ALL AND COPY THIS ENTIRE LINE
   (Ctrl+A then Ctrl+C)

─────────────────────────────────────

STEP 4: Add public key to server (cPanel)
───────────────────────────────────────────

A. Open browser and login to cPanel:
   https://cyimo-whm-private.aos.rw:2083/

   Username: curac
   Password: (your cPanel password)

B. Search for "SSH" in the search box

C. Click "SSH Access" or "Manage SSH Keys"

D. Click "Import Key"

E. In the text area, paste your public key (from STEP 3)

F. Click "Import"

G. You should see your key listed as "Authorized"

Done! ✅

─────────────────────────────────────

STEP 5: Test SSH connection
────────────────────────────
Open PowerShell and paste:

   ssh -p 2083 curac@cyimo-whm-private.aos.rw "echo test"

EXPECTED RESULT: You see "test" printed

IF YOU SEE "test":
   ✅ SUCCESS! SSH is working!

IF YOU SEE "Permission denied":
   ❌ Key not on server yet
   └─ Go back to STEP 4 and make sure key was imported

IF YOU SEE "Connection refused":
   ❌ Server not responding
   └─ Check server is online

─────────────────────────────────────

STEP 6: Verify Git works
─────────────────────────
Open PowerShell and paste:

   ssh -p 2083 curac@cyimo-whm-private.aos.rw "cd /home/curac/umis && git log --oneline -3"

EXPECTED RESULT: You see a list of recent commits

IF YOU SEE COMMITS:
   ✅ SUCCESS! Git is working!

IF YOU SEE "not a git repository":
   ⚠️ Need to initialize git on server
   └─ Run this command:

   ssh -p 2083 curac@cyimo-whm-private.aos.rw << 'EOF'
   cd /home/curac/umis
   git init
   git remote add origin https://github.com/niyongaboemmy/cur-mis.git
   git fetch origin main
   git checkout main
   EOF

   Then try STEP 6 again

================================================================================
✅ YOU'RE DONE!
================================================================================

If you passed all 6 steps, SSH is fully configured! 🎉

Now:
   1. Push code to GitHub: git push origin main
   2. GitHub Actions automatically deploys
   3. Production has your code in 10 seconds
   4. Done! ✅

================================================================================
❌ IF SOMETHING WENT WRONG
================================================================================

Most common issue: "Permission denied"

SOLUTION:
   1. Go back to cPanel
   2. Make sure your key shows as "Authorized"
   3. If not authorized, click "Authorize" button
   4. Try SSH test again (STEP 5)

Other issues?
   See SSH_CONFIGURATION_GUIDE.md for detailed troubleshooting

================================================================================
🧪 TEST AUTOMATIC DEPLOYMENT
================================================================================

Once SSH works, test that automatic deployment works:

1. Push an empty test commit:

   git commit --allow-empty -m "test: verify ssh setup"
   git push origin main

2. Go to GitHub Actions:
   https://github.com/niyongaboemmy/cur-mis/actions

3. Wait 10-15 seconds and refresh

4. Look for the new commit at the top

5. Check its status:
   🟢 GREEN = ✅ Deployment successful!
   🟡 YELLOW = ⏳ Still deploying (wait more)
   🔴 RED = ❌ Failed (check logs)

If you see GREEN, automatic deployment is working! 🎉
