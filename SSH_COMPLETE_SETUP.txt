⚡ SUPER QUICK VERSION (IF YOU'RE IN A HURRY)
================================================================================

Open PowerShell and run these 6 commands:

1. Check keys:
   ls $env:USERPROFILE\.ssh\

2. If no id_rsa, create it:
   ssh-keygen -t rsa -b 4096 -f "$env:USERPROFILE\.ssh\id_rsa" -N ""

3. Get public key:
   Get-Content $env:USERPROFILE\.ssh\id_rsa.pub

4. Copy the output (entire line starting with "ssh-rsa...")

5. Login to cPanel and add it:
   https://cyimo-whm-private.aos.rw:2083/
   → Search: SSH
   → Click: Manage SSH Keys
   → Click: Import Key
   → Paste key
   → Click: Import

6. Test it works:
   ssh -p 2083 curac@cyimo-whm-private.aos.rw "echo test"

✅ If you see "test" → Success! SSH is ready!

================================================================================
🔑 WHAT IS SSH?
================================================================================

SSH = Secure Shell

Think of it as:
   🔓 Door locked with your fingerprint
   🔐 No one can open it except you
   🔑 Your key is split into:
      • Private key (your fingerprint - keep secret!)
      • Public key (the lock - can put anywhere)

When you connect:
   Your Computer ← [Match?] → Server
   (Private Key)  → ✅ Yes → Allowed!
                  → ❌ No → Denied!

================================================================================
🆘 TROUBLESHOOTING
================================================================================

PROBLEM: "Permission denied (publickey)"
└─ REASON: Public key not on server
└─ SOLUTION:
   1. Go back to cPanel (STEP 3)
   2. Make sure key is imported and authorized
   3. Try again

PROBLEM: "Connection refused"
└─ REASON: Server not responding
└─ SOLUTION:
   1. Check server is online
   2. Check internet connection
   3. Try IP: ssh -p 2083 curac@197.243.30.91

PROBLEM: "Could not resolve hostname"
└─ REASON: DNS issue
└─ SOLUTION:
   1. Try IP address instead: ssh -p 2083 curac@197.243.30.91
   2. Check internet connection

PROBLEM: "not a git repository"
└─ REASON: Git not initialized
└─ SOLUTION:
   Run this command to initialize:

   ssh -p 2083 curac@cyimo-whm-private.aos.rw << 'EOF'
   cd /home/curac/umis
   git init
   git remote add origin https://github.com/niyongaboemmy/cur-mis.git
   git fetch origin main
   git checkout main
   EOF

================================================================================
🔒 SECURITY REMINDER
================================================================================

✅ DO:
   • Keep id_rsa private (only your computer)
   • Back up your SSH keys
   • Use 4096-bit keys
   • Rotate keys yearly

❌ DON'T:
   • Share id_rsa
   • Put id_rsa on GitHub
   • Email private key
   • Use weak keys
