🔐 SECURITY
================================================================================

✅ Authentication:
   - ApplicantMiddleware verifies student is authenticated
   - Each student can ONLY access their own application

✅ Authorization:
   - student_id comes from admission_offers table (immutable)
   - Backend validates ownership before returning student_id
   - student_id cannot be manipulated by client

✅ Document Type Lock:
   - URL parameter: type=admission_letter (only this type)
   - applicant=1 parameter ensures admission template used
   - Cross-document access prevented

   Authenticated Student
        ↓
   /api/applicant/application/:id
        ↓
   Backend verifies ownership
        ↓
   Returns student_id from admission_offers
        ↓
   Frontend redirects to generate_document.php
        ↓
   Student sees ONLY their letter

🔗 URL FORMAT
================================================================================

Before (Token-based):
/api/portal/admission-letter?token={letter_token}

After (Student-ID based):
/umis/documents/all_certificate/generate_document.php
  ?type=admission_letter
  &student_id={applicant_student_id}
  &file_name=Admission_Letter_FORMAT.pdf
  &applicant=1

Parameters:
├─ type: admission_letter (document type)
├─ student_id: From admission_offers.student_id (specific to applicant)
├─ file_name: Admission_Letter_FORMAT.pdf (default filename)
└─ applicant: 1 (use applicant letter template)
